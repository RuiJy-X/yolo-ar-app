# SkySight software-box packaging concept

Generated with the built-in imagegen tool as a visual packaging concept.

## Direction

Matte white software box, deep blue spine, restrained red signature, pale blue contour-line graphics, and an aerial-monitoring motif. The presentation shows front, spine, and back views.

The supplied drone emblem and wordmark served as brand references. The back-panel application image uses the actual captured SkySight application as its reference. Generated mockup artwork may reinterpret fine logo and screenshot details; production artwork should place the original supplied assets directly.

## Packaging copy

Front:
- DESKTOP APPLICATION
- SKYSIGHT
- See the action. Support the response.
- AI-powered action recognition
- Recorded analysis · Live camera · Drone monitoring

Back:
- From footage to insight.
- Analyze recorded video.
- Review action logs and timelines.
- Monitor camera and drone feeds.
- Supporting disaster-response awareness.
- In support of SDG 13: Climate Action.

The tagline is proposed packaging copy, not an attributed existing brand slogan. No performance or endorsement claims are included. Physical dimensions, material specifications, printer bleed, and an engineered dieline remain to be set for manufacturing.
